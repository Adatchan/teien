# CSV の項目定義（データ定義書）

管理画面（`/master`）からダウンロードできる CSV の仕様です。
デジタル庁「[機械判読可能なデータの表記方法の統一ルール](https://github.com/digital-go-jp/machine_readability_rule)」に沿って作っています。

## ファイルの一覧

| ファイル | URL | 1 行の単位 | 主な用途 |
|---|---|---|---|
| 当日券の売上（手集計用） | `/api/master/sales_ja.csv` | 1 回の会計 | Excel で開いて人が集計する（日本語の見出し・券種ごとの枚数が 1 列ずつ） |
| 取り置きの一覧と受け渡し | `/api/master/reservations.csv` | 1 件の取り置き | 受け渡しの状況・受付で受け取った額の確認（項目は [reservation-csv.md](reservation-csv.md)） |
| 当日券の会計（データ分析用） | `/api/master/sales.csv` | 1 回の会計 | 売上・支払方法・時間帯の集計 |
| 当日券の明細（データ分析用） | `/api/master/sale_items.csv` | 1 回の会計 × 1 券種 × 1 セットの種類 | 券種ごと・セットごとの枚数と金額 |
| 団員ごとの精算 | `/api/master/members.csv` | 1 人の団員 | 終演後に団員から回収する額と回収の状況（団員・メールアドレス・件数・枚数・受け渡し済みの枚数・回収する額・回収済み・未回収・回収（済／一部／未））|
| 団員ごとの精算（Excel） | `/api/master/members.xlsx` | — | 印刷・共有用。シート「団員ごとの精算」と「明細」 |
| 取り置きの様式 | `/api/master/reservations_template.csv` | — | 取り込みの様式（見出しと記入例） |

- どれも管理画面のログインが必要です。
- **1 つのファイルには 1 つの公演の分だけ**が入ります。管理画面で開いている公演の分です（URL の `?project=<公演の番号>` で指定）。
- `sales.csv` と `sale_items.csv` は `sale_id`（会計 ID）でつながります。
- ファイル名は `teien_p<公演の番号>_<種類>_<作成日時 YYYYMMDDHHMM（日本時間）>.csv` です。

## 共通の形式

| 項目 | 内容 |
|---|---|
| 形式 | CSV（RFC 4180 準拠）。区切り文字はカンマ `,` |
| 文字コード | UTF-8。既定で先頭に BOM を付ける（Windows の Excel で文字化けしないため）。URL の末尾に `&bom=0` を付けると BOM なし |
| 改行 | CRLF。最後の行の後にも改行あり |
| 1 行目 | 項目名。データ分析用は英小文字・数字・`_` の物理名、手集計用と取り置きは日本語。2 行目からデータ |
| 金額 | 円の整数。桁区切りのカンマ・`¥`・`円` は付けない |
| 日時 | ISO 8601、日本時間（例: `2027-06-01T13:05:12+09:00`） |
| 空欄 | 「値がない」を表す。ゼロとは区別する |
| 取消 | レジで取り消した当日券の会計は含めない（データベースには取消の印つきで残っている） |
| 数式対策 | 文字列の値が `=` `+` `-` `@` で始まるときは、Excel が数式として実行しないよう先頭に `'` を付ける |

## sales_ja.csv（当日券の売上・手集計用）

| 列 | 内容 |
|---|---|
| 会計番号 | レジの `#`（公演ごとに 1 から） |
| 日付・時刻 | `2027/06/01`・`13:05:12`（日本時間） |
| 支払方法・担当者 | |
| （券種名）(枚) | 券種ごとの枚数（今の券種の並び順。販売停止で売れていない券種は出さない） |
| 枚数計(枚) | 枚数の合計 |
| 合計(円) | お客さんから受け取った金額 |
| 内容（参考） | 例 `一般3枚（2枚セット×1＋1枚×1）` |

## sales.csv（当日券の会計）

| 項目名 | 型 | 内容 |
|---|---|---|
| `sale_id` | 整数 | 会計 ID（全公演で重ならない） |
| `project_id` | 整数 | 公演の番号 |
| `order_no` | 整数 | 会計番号（レジの `#`。公演ごとに 1 から） |
| `sold_at` | 日時 | 会計した時刻（オフラインで打った会計は端末で打った時刻） |
| `business_date` | 日付 | `sold_at` の日本時間の日付 |
| `payment_method` | 文字列 | 支払方法 |
| `ticket_quantity` | 整数 | 枚数の合計 |
| `total_amount_yen` | 整数 | 合計金額 |
| `staff_name` | 文字列 | レジの担当者名 |

## sale_items.csv（当日券の明細）

| 項目名 | 型 | 内容 |
|---|---|---|
| `sale_id` | 整数 | `sales.csv` の `sale_id` |
| `sold_at` / `business_date` | 日時 / 日付 | 会計の時刻・日付 |
| `product_id` | 整数 | 券種 ID |
| `ticket_type` | 文字列 | 券種名（会計した時点の名前） |
| `pack_size` | 整数 | セットの枚数（1 枚売りは 1） |
| `pack_price_yen` | 整数 | セットの価格 |
| `pack_count` | 整数 | そのセットの数 |
| `quantity` | 整数 | 枚数（`pack_size × pack_count`） |
| `amount_yen` | 整数 | 金額（`pack_price_yen × pack_count`） |
| `unit_name` | 文字列 | 単位（例: 枚） |
| `is_mixed_pack` | 0/1 | ほかの券種と合わせて組んだセットか（1 = そう。金額は枚数の割合で分けている） |
| `mixed_pack_label` | 文字列 | 合わせて組んだセットの組み方（例: `2枚セット×1`）。そうでなければ空欄 |

1 回の会計の `amount_yen` の合計は、`sales.csv` の `total_amount_yen` と 1 円もずれずに一致します。
