# 取り置きの CSV のダミー（いろいろな書き方を試す用）

管理画面の「券種・価格」で **一般**（1枚 1,500円・2枚 2,800円）、**学生**（1枚 500円）、**招待**（0円・販売中とウェブ予約に出すを外す）を登録してから、「取り置き」で取り込むと試せます。取り込む前の確認画面で中身が見られるので、「取り込む」を押さずに「やめる」でもかまいません。

## dummy-reservations.csv（正しいもの・10件）

同じ内容の Shift_JIS 版（Excel で保存した CSV と同じ文字コード）が `dummy-reservations-sjis.csv` です。

| 番号 | お客さん | 試していること |
|---|---|---|
| 1 | 倉敷 さくら | 支払「団員」。団員 山田 花子・団員のメール入り → 終演後に団員から回収 |
| 2 | 岡山 太郎 | 支払「当日」 → 受付で 1,500円 受け取る。連絡先入り |
| 3 | 津山 花子 | **同じ番号で 2 行**（一般1枚＋学生2枚 → 1 件にまとまる）。支払「済」 |
| 4 | 玉野 次郎 | フリガナが**ひらがな**。支払が**空欄で団員の名前あり** → 団員から回収 |
| 5 | 総社 美咲 | **招待（0円）**。支払が空欄で団員なし → 当日（代金なし）。備考 |
| 6 | 笠岡 健 | **金額の列で上書き**（一般3枚 4,200円のところ 4,000円）。割引の例 |
| 7 | 井原 由美 | 団員「山田　花子」（**全角スペース**）→ 1 の山田 花子と同じ人として精算にまとまる。備考 |
| （空欄） | 高梁 優 | **番号なし** → 自動で 9 番 |
| （空欄） | 新見 翔 | 番号なし → 自動で 10 番。団員「佐藤一郎」（**空白なし**）→ 4 の佐藤 一郎と同じ人 |
| 8 | 備前, 長船 | 氏名に**カンマ**、備考に**改行**（ダブルクォートで囲む CSV の書き方） |

合計 17 枚・受付で受け取る額 6,000円・団員から回収 7,600円（山田 花子 5,600円・佐藤 一郎 2,000円）。

## dummy-reservations-errors.csv（間違いの例）

取り込もうとすると、行番号つきで直すところが 7 か所出て、**1 件も取り込まれません**（38 番の正しい行も）。

| 行 | 間違い |
|---|---|
| 2 | 氏名が空 |
| 3 | 券種名の打ち間違い（「一船」） |
| 4 | 枚数が数字でない（「ニ」） |
| 5 | 支払が読めない（「たぶん」） |
| 6 | 金額が数字でない（「千円」） |
| 8 | 同じ番号 36 に別の人 |
| 10 | 同じ番号 37 で支払が食い違う（済／当日） |
